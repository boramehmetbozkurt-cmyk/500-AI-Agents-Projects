# ORBYTHRA Commercial Metrics Scoreboard

Status: operating template. Blank/target fields must not be represented as achieved results.

| Metric | Current verified | Target / threshold | Evidence source |
|---|---:|---:|---|
| Paid enterprise customers | 0 verified in repository | 3+ initial conversions | signed contracts / invoices |

## Funnel

Track qualified enterprise opportunities, pilots started, pilot acceptance, paid conversion, median sales cycle, loss reason and pipeline coverage. Keep CRM evidence separate from technical readiness claims.

## Unit economics

Track gross margin, inference/provider costs, hosting/database/observability cost, support hours per customer, customer acquisition cost and CAC payback. Usage metering in `/v1/enterprise/usage/*` supplies technical units but is not itself revenue evidence.

## Product value

Track evidence-pass improvement, unsupported-claim reduction, correct abstention, traceability coverage, reviewer time saved, policy violations prevented and p95 latency. Every published metric should name the evaluated population, period, baseline and methodology.

## $100M evidence discipline

A valuation narrative should distinguish:
- internal IP/replacement-value estimate;
- financing valuation actually agreed by investors;
- acquisition indications/offers;
- recurring revenue metrics;
- independent technical validation.

Never convert an internal test score or target ARR into a claim that a transaction value has been achieved.
