# ORBYTHRA Enterprise Pilot Playbook

Goal: convert technical evaluation into auditable customer value without moving success criteria after results are known.

## 1. Entry requirements

- Named customer sponsor and technical owner.
- Defined AI/agent workflow and consequence level.
- 100–500 representative scenarios where practical, including negative controls.
- Data handling classification, permitted providers/regions and retention.
- Written baseline: current model/provider, current failure rate or review workload where measurable.
- Predeclared acceptance criteria before execution.

## 2. Recommended pilot phases

### Phase A — Baseline
Run the customer's current workflow without ORBYTHRA controls and capture disposition, traceability, evidence quality, latency and review burden.

### Phase B — ORBYTHRA gated run
Use the same scenario set through evidence verification, enterprise policy, human-review gates and audit trail. Freeze configuration before scoring.

### Phase C — Negative controls
Require missing evidence, contradiction, stale evidence, low-authority sources, provider/region violation, cross-workspace access and high-risk/no-human-approval cases.

### Phase D — Remediation and retest
Classify failures; fix reproducible product defects; rerun the frozen scenario set plus regression controls. Preserve both first-run and retest results.

## 3. Customer KPI scorecard

Measure only what can be evidenced:
- disposition accuracy against agreed expected behavior;
- evidence-gate pass rate;
- unsupported/guarded claim rate;
- traceability coverage;
- abstention correctness;
- critical policy-block correctness;
- p50/p95 latency;
- evaluator/reviewer time per case;
- incidents/escalations;
- workflow completion rate.

Commercial KPIs after conversion: ACV, time to production, expansion usage, renewal, support burden and net revenue retention.

## 4. Acceptance package

Customer receives: scenario manifest, configuration/policy version, release SHA, benchmark result, failure list, audit references, remediation log and final acceptance statement. A customer acceptance statement must come from the customer; ORBYTHRA cannot self-issue it.

## 5. Conversion motion

Pilot -> acceptance review -> production security questionnaire/DPA -> commercial order -> production deployment -> 30/60/90-day value review -> renewal/expansion plan.

## 6. Referenceability

Do not publish the customer name, logo, case-study metrics or quotes without written permission. Maintain a private reference status separately from public marketing permission.
